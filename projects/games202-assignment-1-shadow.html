Assignment 01 — Shadow Mapping

实时阴影与 球谐环境光

在基础 WebGL Phong 管线中加入方向光阴影、软阴影过滤和 SH 环境光，把“模型被照亮”推进到 “物体和地面有稳定接触关系、阴影边缘有尺度感”的实时画面。

01 — Problem

核心思路

Shadow Map 的关键是把场景先从光源视角渲染出深度图，再在主相机视角中把片元投影回光源空间比较深度。 为了避免硬边缘和阴影痤疮，我加入了斜率相关 bias、Poisson 采样、blocker search 和可变半径 PCF。

环境光部分使用三阶 SH 系数近似低频漫反射，让阴影区域仍保留环境色，而不是掉成纯黑。

02 — Pipeline

两个 Pass 的实现管线

Pass 01

光源深度 Pass

使用方向光的正交相机生成 light view-projection matrix。WebGL1 环境下没有直接依赖深度纹理，因此用颜色附件写入深度，同时保留 renderbuffer 做正确遮挡。

Pass 02

主相机着色 Pass

主 pass 将世界坐标投影到 shadow map UV，比较当前深度与 map 深度。阴影因子再乘到直接光上，环境光由 SH irradiance 提供低频补光。

03 — Important Code

PCSS 式软阴影核心

先搜索 blocker，估算平均遮挡深度，再根据接收点和遮挡点的距离估算半影宽度，最后用可变半径 PCF 过滤阴影。

phongFragment.glslGLSL
float pcfShadowFactor() {
  vec3 proj = vShadowCoord.xyz / vShadowCoord.w;
  vec2 uv = proj.xy * 0.5 + 0.5;
  float cur = proj.z * 0.5 + 0.5;

  vec3 n = normalize(vNormal);
  vec3 l = normalize(uLightPos - vFragPos);
  float ndotl = max(dot(n, l), 0.0);
  float bias = max(0.003, 0.008 * (1.0 - ndotl));

  vec2 searchScale = texelSize * (1.5 + lightRadius);
  float blockerSum = 0.0;
  float blockerCount = 0.0;
  // Poisson taps: if sampled depth is closer than receiver, it is a blocker.

  float avgBlockerDepth = blockerSum / blockerCount;
  float penumbra = clamp((cur - avgBlockerDepth) /
                         max(avgBlockerDepth, 1e-4), 0.0, 1.0);

  vec2 filterScale = texelSize *
      (1.0 + penumbra * uPenumbraScale * lightRadius * 4.0);
  return poissonPcfAverage(uv, cur, bias, filterScale);
}
04 — Stability

抗伪影策略

  • 使用 slope-scaled bias 缓解 grazing angle 下的自阴影条纹。
  • 对大半影 filter radius 做上限，避免低精度 shadow map 被过度放大。
  • 加入极小 per-fragment jitter，降低规则采样带来的条带感。
