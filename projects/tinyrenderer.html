Featured Project

tinyrenderer

一个不用任何图形API，仅有必要的识别obj文件的库的最小渲染器。

项目概述

这个实现不是“做一个能出图的玩具”，而是把现代渲染管线拆开后逐段落地。源码里把 Camera、MVP 变换、光栅化、透视正确插值、片元着色、ZBuffer 与纹理采样连成了完整的数据流，目标是建立对真实引擎渲染路径的可解释认知。

源码驱动的渲染流程

  • 入口在 `main.cpp`：读取 OBJ 路径与各类贴图路径，初始化渲染参数与输出分辨率。
  • `lookat / perspective / viewport` 完成从世界空间到屏幕空间的矩阵设置。
  • `render_model()` 遍历每个三角面，并执行细分后再进入着色阶段。
  • `rasterize()` 中进行重心坐标覆盖测试、透视正确重建、深度比较与写回。
  • `CurvedBlinnPhongShader::fragment()` 执行法线贴图、漫反射、高光与纹理合成。
  • 最终写入 `framebuffer.tga`，形成离线渲染输出。

和 GPU Pipeline 的一一映射

Vertex Processing：`shader.vertex()` 输出 clip 坐标，对应 VS 输出。

Rasterization：`rasterize()` 做覆盖判定与像素遍历，对应固定功能光栅阶段。

Fragment Shading：`fragment(bar)` 以重建属性计算颜色，对应 PS/FS。

Depth Test：`if (z <= zbuffer[idx]) continue;` 对应 Early/Late-Z 的概念模拟。

Render Target：`framebuffer.set(x, y, color)` 对应 RT 写入。

相比基础 TinyRenderer 的扩展点

  • 支持 normal / diffuse / specular 三类贴图开关与路径注入。
  • 引入可控曲面细分：`subdivision_level` + `curve_strength`，在 CPU 端做曲面近似。
  • 使用 `invert_transpose()` 法线矩阵处理视空间法线，保持变换正确性。
  • 实现 Tangent/Bitangent 计算，将法线贴图从切线空间还原到视空间。
  • 支持较高分辨率离线输出（默认可达 4800x4800），便于细节检查。

工程化组织与调试价值

  • `RenderSettings` 把渲染参数集中管理，降低实验迭代成本。
  • `Model::sample2D()` 提供统一纹理采样入口，便于替换采样策略。
  • 渲染阶段拆分明确：模型加载、几何处理、着色、输出各司其职。
  • 方便追加可视化输出（Depth / Normal / Wireframe）进行阶段性验证。

2) OBJ 顶点/法线/UV/面索引读取（`Model.cpp`）

if (!line.compare(0, 2, "v ")) { ... verts.push_back(v); }
else if (!line.compare(0, 3, "vn ")) { ... norms.push_back(n); }
else if (!line.compare(0, 3, "vt ")) { ... uvs.push_back(uv); }
else if (!line.compare(0, 2, "f ")) {
  ... facet_vrt.push_back(v_idx - 1);
  ... facet_uv.push_back(vt_idx ? (vt_idx - 1) : -1);
  ... facet_nrm.push_back(vn_idx ? (vn_idx - 1) : -1);
}

3) 光栅化 + 透视正确插值 + ZBuffer（`ourGL.cpp`）

double alpha = (px * v1y - v1x * py) / denom;
double beta  = (v0x * py - px * v0y) / denom;
double gamma = 1.0 - alpha - beta;
if (alpha < 0 || beta < 0 || gamma < 0) continue;

double z = alpha * ndc[0].z + beta * ndc[1].z + gamma * ndc[2].z;
int idx = x + y * framebuffer.width();
if (z <= zbuffer[idx]) continue;

double a = alpha / clip[0].w, b = beta / clip[1].w, c = gamma / clip[2].w;
double sum = a + b + c;
vec3 bar = (sum != 0.0) ? vec3{ a / sum, b / sum, c / sum } : vec3{ alpha, beta, gamma };
auto fr = shader.fragment(bar);
zbuffer[idx] = z;
framebuffer.set(x, y, fr.second);

项目定位

它是我继续走向 DirectX / Vulkan / Unreal 渲染体系前的“底层认知样机”。重点价值是把抽象概念落到代码路径，之后面对引擎渲染问题时，可以快速判断问题属于几何阶段、光栅阶段还是片元阶段。

后续迭代计划

  • 增加多 Pass 输出：Albedo / Normal / Depth 分离图。
  • 补充裁剪阶段与背面剔除策略，完善几何阶段鲁棒性。
  • 加入线性空间处理与基础后处理，提升结果可信度。
  • 把 CPU 版本数据流进一步映射到 API 级 RenderGraph 思维。
