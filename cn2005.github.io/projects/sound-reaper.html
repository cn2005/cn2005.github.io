Concept

节奏即力量

本作属于 Rhythm-Action 类型。玩家在音乐节拍中通过精准攻击与闪避建立节奏连击， 节奏表现会直接影响攻击伤害、技能冷却和连击倍率，让听觉反馈与操作策略形成强绑定。

详细文档： WPS 云文档

System

核心技术

  • Rhythm-Driven Combat： 通过 BPM 计算每拍时间，在玩家输入时进行时间余数判定，实现 Perfect、Good、Miss 三档节奏反馈。
  • RhythmMultiplier 事件系统： 同时承担输入监听与事件广播，让角色、技能与攻击逻辑能根据判定结果动态响应。
  • Modifier 强化架构： 作为战斗逻辑中间层，把输入、子弹生成和伤害结算解耦，使新强化可以在不改核心战斗代码的情况下叠加生效。
  • Roguelike 强化生成： 关卡结束后按稀有度概率抽取强化，并映射到 UI 选项，支持数值型与行为型强化。
  • Unreal Engine 实现： 整合 Behavior Tree、对象池、Niagara 特效、射线检测和碰撞体检测完成战斗反馈与性能优化。
