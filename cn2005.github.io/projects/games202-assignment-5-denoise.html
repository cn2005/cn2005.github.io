01 — Concept

谁可以互相借样本

降噪的难点不是“平均”，而是判断哪些像素属于同一表面和同一材质区域。 所以滤波权重不能只看颜色，还要看 depth、normal、position 和 object/material ID。

单帧结果再进入时域累积，让随机噪声被多帧平均，但历史颜色必须被 clamp，避免拖影和鬼影。

02 — Pipeline

空间滤波与时域重投影

Spatial

联合双边单帧滤波

对每个像素在半径内取邻域样本，权重由空间距离、颜色差、法线夹角、平面距离和 ID 一起决定。同一表面内部强平滑，轮廓和材质边界弱平滑或拒绝。

Temporal

重投影与历史累积

使用当前像素 world position 投影到上一帧屏幕空间，读取历史 accumulated color。如果深度、法线或 ID 不一致，则历史无效；有效历史经过邻域颜色盒裁剪后做 EMA。

03 — Important Code

降噪器数据流

先 filter current frame，再重投影历史，最后做 temporal accumulation。

denoiser.cppC++
Buffer2D<Float3> Denoiser::ProcessFrame(const FrameInfo &frameInfo) {
  Buffer2D<Float3> filteredColor = Filter(frameInfo);

  if (m_useTemportal) {
    Reprojection(frameInfo);
    TemporalAccumulation(filteredColor);
  } else {
    Init(frameInfo, filteredColor);
  }

  Maintain(frameInfo);
  m_useTemportal = true;
  return m_accColor;
}
Joint Bilateral WeightPseudo
weight =
  spatialGaussian(distance(p, q), sigmaCoord) *
  depthPlaneWeight(position, normal) *
  normalGaussian(1 - dot(Np, Nq), sigmaNormal) *
  colorGaussian(length(Cp - Cq), sigmaColor) *
  sameObjectOrMaterialId(p, q);

filtered[p] = sum(weight * beauty[q]) / sum(weight);
04 — Clamp

Temporal Clamp

取当前滤波结果周围 3x3 或 5x5 邻域的颜色范围，将历史颜色限制在这个范围内。 这样可以减少物体移动、遮挡变化或历史错误带来的拖影。
