Rendering Suite / GAMES202

高质量实时渲染

基于 GAMES202 的五个实时渲染作业整理，从阴影、预计算光照、屏幕空间实时光追、 PBR 材质到时空降噪，串起一条面向高质量实时画面的工程路径。

Scope Assignment 1 - 5
Stack WebGL / GLSL / C++ / Nori
Focus Lighting / Materials / Denoising
Output 实时 Demo 与离线序列结果

Sequence

从单项算法到完整画面链路

这组作业不是孤立算法展示，而是逐步补齐实时渲染画面所需的关键模块： 先解决可控阴影和环境光，再把全局光照预计算为可实时查询的数据，随后进入屏幕空间间接光、 物理材质和降噪稳定性。每一项都保留统一的视频入口，托管链接补齐后可以直接观看。

01

Assignment 1

Shadow Mapping / SH Ambient

实时阴影与球谐环境光

在 WebGL 渲染框架里扩展 Phong 管线，引入方向光 Shadow Map、PCF/PCSS 式软阴影、 斜率相关 bias、地面接收阴影以及来自环境 cubemap 的低阶 SH 漫反射环境光。 目标是让基础实时场景从“有光照”推进到“有可信接触关系与空间层次”。

Directional Shadow Map PCF / Blocker Search Slope-Scaled Bias SH Irradiance WebGL FBO

Assignment 2

Precomputed Radiance Transfer

PRT 预计算辐射传输

使用 Nori/C++ 预处理环境光与物体传输函数，把 cubemap 投影到二阶球谐系数， 并为模型顶点计算 unshadowed、shadowed 与 interreflection 类型的传输系数。 运行时在 WebGL 端读取 light/transport 数据，在顶点属性与 shader 中完成实时重光照。

Assignment 3

Screen-Space Ray Tracing

屏幕空间实时光追与间接光

搭建基于 G-Buffer 的屏幕空间管线，输出 diffuse、depth、normal、shadow 和 world position。 在 SSR/SSRT shader 中进行半球采样、ray marching、厚度判断与二分细化， 将命中的屏幕空间点用于估计单次反弹间接光，并把 direct/indirect lighting 分离写入 MRT。

Assignment 5

Denoising / Temporal Stability

单帧滤波与时域累积降噪

以 EXR 序列为输入，读取 beauty、depth、normal、position、ID 与相机矩阵， 组织离线降噪器的数据结构。核心思路是用几何/材质信息引导联合双边滤波， 再通过重投影、temporal clamp 与指数滑动平均积累历史结果，让低采样画面在运动中保持稳定。
