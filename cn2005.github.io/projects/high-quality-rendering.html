Featured 05 — Rendering Suite / GAMES202

高质量实时渲染

基于 GAMES202 的五个实时渲染作业整理，从阴影、预计算光照、屏幕空间实时光追、PBR 材质到时空降噪， 串起一条面向高质量实时画面的工程路径。

Scope
Assignment 1 – 5
Stack
WebGL / GLSL / C++ / Nori
Focus
Lighting / Materials / Denoising
Output
实时 Demo 与离线序列结果
Sequence

从单项算法到完整画面链路

这组作业不是孤立的算法展示，而是逐步补齐实时渲染画面所需的关键模块：先解决可控阴影和环境光， 再把全局光照预计算为可实时查询的数据，随后进入屏幕空间间接光、物理材质和降噪稳定性。

每一项都附有技术拆解与演示视频。

01
Shadow Mapping / SH Ambient

实时阴影与球谐环境光

在 WebGL 渲染框架里扩展 Phong 管线，引入方向光 Shadow Map、PCF/PCSS 式软阴影、斜率相关 bias、 地面接收阴影以及来自环境 cubemap 的低阶 SH 漫反射环境光。

Shadow MapPCF / Blocker SearchSlope-Scaled BiasSH Irradiance
Video 技术拆解
02
Precomputed Radiance Transfer

PRT 预计算辐射传输

使用 Nori/C++ 预处理环境光与物体传输函数，把 cubemap 投影到二阶球谐系数，并计算 unshadowed、 shadowed 与 interreflection 传输系数；运行时在 shader 中完成实时重光照。

Spherical HarmonicsShadowed PRTInterreflectionRelighting
Video 技术拆解
03
Screen-Space Ray Tracing

屏幕空间实时光追与间接光

基于 G-Buffer 的屏幕空间管线，在 shader 中进行半球采样、ray marching、厚度判断与二分细化， 估计单次反弹间接光，并把 direct / indirect lighting 分离写入 MRT。

Deferred G-BufferRay MarchingBinary RefinementMRT
Video 技术拆解
04
PBR / Kulla-Conty

物理材质与多重散射补偿

实现 GGX 微表面、Smith 几何项、Schlick Fresnel、Disney diffuse 与 metallic/roughness 材质； 通过 Kulla-Conty、BRDF LUT 与 Eavg LUT 补偿高粗糙金属的能量损失。

GGX MicrofacetDisney DiffuseKulla-ContyBRDF / Eavg LUT
Video 技术拆解
05
Denoising / Temporal Stability

单帧滤波与时域累积降噪

以 EXR 序列为输入，用几何与材质信息引导联合双边滤波，再通过重投影、temporal clamp 与指数滑动平均积累历史结果，让低采样画面在运动中保持稳定。
