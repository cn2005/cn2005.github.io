Featured Project / Stylized Rendering

仿终末地渲染

根据终末地美术效果进行风格化复现，用 NPR 与 PBR 混合方式处理角色体积、材质高光、描边与面部阴影。

Direction NPR / PBR Hybrid
Material MatCap / GGX / Rim Light
Feature 法线偏移描边与 SDF 面部阴影
Goal 稳定的二次元角色光照层次

Lighting

多模型融合的 NPR 角色光照

结合 Lambert 漫反射、Rim Light、AO 与 GGX Specular 构建非真实感角色光照模型。 通过摄像机法线与顶点法线混合优化光照方向，让角色在保持二次元风格的同时具备稳定体积感。

Material

MatCap 与高光控制

使用 MatCap 映射增强材质表现，并通过高光遮罩控制 Specular 分布， 让角色表面反射在不同光照环境下保持一致的风格化观感。

Silhouette

基于法线偏移的角色轮廓描边

通过 Normal Offset 生成屏幕空间描边，实现稳定的角色轮廓线效果。 相比传统扩展模型描边，这种方案可以减少穿模和深度错误，提升复杂场景中的视觉识别度。

Face

基于深度与 SDF 的面部遮挡

使用 SDF 面部阴影系统生成稳定的脸部阴影分区，并结合 DepthFade 与朝摄像机偏移， 解决眉毛被头发遮挡的问题，保持角色表情清晰。

Hair

KKS 风格头发阴影与调色

通过深度检测头发阴影区域，对阴影像素进行 RGB 到 HSV 转换并调整饱和度， 再结合 SceneDepth 控制透明度衰减，形成更有层次的风格化头发阴影。
