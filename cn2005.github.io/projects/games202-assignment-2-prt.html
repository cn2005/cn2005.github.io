Assignment 02 — Precomputed Radiance Transfer

PRT 预计算 辐射传输

将环境光和表面传输函数都投影到球谐基上。昂贵的可见性、遮挡和间接反射在预处理阶段完成， 运行时只需要做低维系数点乘，就能快速切换环境光并保持柔和全局光照效果。

01 — Concept

把积分变成点乘

PRT 的本质是把渲染方程里的低频环境光积分压缩为球谐空间中的系数运算。 环境 cubemap 被投影成 L，每个顶点的传输函数被投影成 T。 运行时颜色近似为 sum(L_i * T_i)，所以环境切换时不需要重新追踪可见性。

02 — Pipeline

离线预计算与运行时重光照

Offline

预计算阶段

  • 读取 6 面 cubemap，根据 texel 对应立体角计算 SH light coefficients。
  • 对每个顶点投影传输函数，支持 unshadowed、shadowed 和 interreflection。
  • 将 light.txt 与 transport.txt 输出给 WebGL runtime 使用。
Runtime

运行时重光照

  • 每个顶点携带 aPrecomputeLT 作为传输系数。
  • 环境光 9 个 RGB SH 系数作为 uniform 传入 shader。
  • 顶点 shader 完成系数点乘，fragment shader 输出低频光照颜色。
03 — Important Code

运行时 SH 系数点乘

prtVertex.glslGLSL
attribute mat3 aPrecomputeLT;
uniform vec3 uL0;
uniform vec3 uL1;
uniform vec3 uL2;
// ... uL3 - uL8

void main(void) {
  highp vec3 c =
      uL0 * aPrecomputeLT[0][0] +
      uL1 * aPrecomputeLT[0][1] +
      uL2 * aPrecomputeLT[0][2] +
      uL3 * aPrecomputeLT[1][0] +
      uL4 * aPrecomputeLT[1][1] +
      uL5 * aPrecomputeLT[1][2] +
      uL6 * aPrecomputeLT[2][0] +
      uL7 * aPrecomputeLT[2][1] +
      uL8 * aPrecomputeLT[2][2];
  vColor = c;
}
04 — Detail

Shadowed 与 Interreflection

shadowed transport 在采样方向上发射 shadow ray，如果被场景遮挡就返回 0。 interreflection 则在命中其他三角形时，用命中点的传输系数插值估计反弹贡献，并做多轮累积。 这让凹陷区域能获得更可信的低频间接光，但代价是预处理更重。

Tradeoff

适用范围

低阶 SH 很适合漫反射、柔和环境光和低频遮挡；不适合高频阴影、镜面反射或快速变化的局部光源。
