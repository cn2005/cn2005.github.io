PBR 与 Kulla-Conty 多重散射

实现以 GGX 为核心的 metallic-roughness 材质，并通过 Kulla-Conty 多重散射补偿解决高粗糙金属能量损失， 让不同 roughness 下的材质过渡更稳定、更符合物理直觉。

01 — Concept

从单次散射到能量补偿

标准微表面 BRDF 在高粗糙度、多次反射场景下会丢失部分能量，金属球会显得偏暗。 Kulla-Conty 的思路是预积分方向性反射能量，用 LUT 估计没有被单次散射带走的部分， 再以平均 Fresnel 构造一个额外多重散射项。

02 — Pipeline

材质模型与环境光

PBR Base

基础材质模型

  • 读取 baseColor、metallic、roughness，并在线性空间计算。
  • specular 使用 GGX NDF、Smith Geometry 和 Schlick Fresnel。
  • diffuse 使用 Disney diffuse，处理 grazing angle 的漫反射变化。
IBL

环境光与 LUT

  • 低频 diffuse 使用 SH irradiance。
  • specular 使用反射方向采样环境近似。
  • BRDF LUT 和 Eavg LUT 为 Kulla-Conty 提供积分结果。
03 — Important Code

Kulla-Conty 多重散射项

KullaContyFragment.glslGLSL
vec3 MultiScatterBRDF(float NdotL, float NdotV) {
  vec3 albedo = pow(texture2D(uAlbedoMap, vTextureCoord).rgb, vec3(2.2));

  vec3 E_o = texture2D(uBRDFLut, vec2(NdotL, uRoughness)).xyz;
  vec3 E_i = texture2D(uBRDFLut, vec2(NdotV, uRoughness)).xyz;
  vec3 E_avg = texture2D(uEavgLut, vec2(0, uRoughness)).xyz;

  vec3 edgetint = vec3(0.827, 0.792, 0.678);
  vec3 F_avg = AverageFresnel(albedo, edgetint);

  vec3 fms = (1.0 - E_o) * (1.0 - E_i) /
             max(PI * (1.0 - E_avg), vec3(0.001));
  vec3 fadd = F_avg * E_avg /
              max(1.0 - F_avg * (1.0 - E_avg), vec3(0.001));
  return fadd * fms;
}
04 — Result

画面收益

对金属材质而言，多重散射补偿可以让粗糙度升高时不至于快速变灰变暗， 材质球序列中的亮度变化会更连续，尤其适合展示材质参数扫描。
