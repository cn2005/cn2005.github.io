Featured 03 — Rendering Engineering

tinyrenderer

不使用任何图形 API，从模型读取、坐标变换、光栅化、透视正确插值、深度测试到纹理采样， 搭建一个可解释的 CPU 渲染器。

Role
渲染工程实现
Pipeline
OBJ / MVP / Rasterization / ZBuffer
Output
离线 TGA 渲染图
Value
把 GPU 管线概念落到代码路径
01 — Overview

项目概述

这个实现不是为了做一个“能出图的玩具”，而是把现代渲染管线拆开后逐段落地。 源码里把 Camera、MVP 变换、光栅化、透视正确插值、片元着色、ZBuffer 与纹理采样连成完整数据流， 目标是建立对真实引擎渲染路径的可解释认知。

02 — Pipeline

源码驱动的渲染流程

Flow

从入口到帧缓冲

  • 入口读取 OBJ 路径、贴图路径、渲染参数与输出分辨率。
  • lookat / perspective / viewport 完成世界空间到屏幕空间的矩阵设置。
  • render_model() 遍历三角面，细分后进入着色阶段。
  • rasterize() 负责重心坐标覆盖测试、透视重建、深度比较与写回。
  • CurvedBlinnPhongShader::fragment() 合成法线贴图、漫反射、高光与纹理颜色。
Mapping

与 GPU Pipeline 的映射

  • Vertex Processing：shader.vertex() 输出 clip 坐标。
  • Rasterization：rasterize() 处理覆盖判定与像素遍历。
  • Fragment Shading：fragment(bar) 重建属性并计算颜色。
  • Depth Test：通过 ZBuffer 模拟 Early/Late-Z 的核心概念。
  • Render Target：framebuffer.set() 完成颜色写入。
03 — Extensions

相比基础 TinyRenderer 的扩展

  • 支持 normal、diffuse、specular 三类贴图开关与路径注入。
  • 引入可控曲面细分，在 CPU 端做曲面近似。
  • 使用 invert_transpose() 处理视空间法线矩阵，保持变换正确性。
  • 实现 Tangent / Bitangent 计算，将法线贴图从切线空间还原到视空间。
  • 支持高分辨率离线输出，方便检查模型、法线与材质细节。
