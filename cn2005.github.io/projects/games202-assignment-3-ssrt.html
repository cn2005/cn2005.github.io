01 — Concept

用屏幕已有信息近似间接光

屏幕空间方法只追踪当前相机能看到的几何。它的好处是实现轻、数据局部、适合实时 demo； 代价是看不到屏幕外或被遮挡的几何。因此实现上要处理出屏、厚度、深度误差和低采样噪声。

02 — Pipeline

G-Buffer 与屏幕空间命中

G-Buffer

几何与材质缓存

第一阶段写入 diffuse、depth、normal、shadow visibility 和 world position。后续 ray marching 和联合滤波都依赖这些稳定通道，而不是直接依赖 noisy color。

SSRT

屏幕空间命中

每个像素按法线半球 cosine stratified sampling，沿采样方向在世界空间步进，投影到屏幕后与 G-Buffer depth 比较；发现穿越后用二分细化命中点。

03 — Important Code

Ray Marching 与二分细化

ssrFragment.glslGLSL
bool RayMarch(vec3 ori, vec3 dir, out vec3 hitPos) {
  vec3 rayDir = normalize(dir);
  vec3 lastPos = ori;
  vec3 curPos = ori + rayDir * RAYMARCH_STEP_SIZE;

  for (int i = 0; i < MAX_RAYMARCH_STEP; i++) {
    vec2 uv = GetScreenCoordinate(curPos);
    float depthDiff = GetDepth(curPos) - GetGBufferDepth(uv);

    if (depthDiff > 0.0 && depthDiff < RAYMARCH_THICKNESS) {
      hitPos = curPos;
      return true;
    }

    if (depthDiff >= RAYMARCH_THICKNESS) {
      vec3 begin = lastPos;
      vec3 end = curPos;
      for (int j = 0; j < RAYMARCH_BINARY_STEP; j++) {
        vec3 mid = (begin + end) * 0.5;
        float midDiff = GetDepth(mid) -
            GetGBufferDepth(GetScreenCoordinate(mid));
        if (midDiff > 0.0) end = mid;
        else begin = mid;
      }
      hitPos = end;
      return true;
    }

    lastPos = curPos;
    curPos += rayDir * RAYMARCH_STEP_SIZE;
  }
  return false;
}
04 — Denoise

空间滤波与时域累积

Spatial

A-trous 联合双边

对 indirect lighting 单独做多轮滤波。权重由空间核、深度差、法线差和 diffuse 差共同决定，每轮 step size 扩张，形成 A-trous 风格的大范围降噪，同时尽量保护边界。

Temporal

TAA 历史累积

当前帧合成后写入 history FBO。历史颜色会被当前 3x3 邻域 min/max clamp，再根据 history weight 混合，减少拖影和过度积累。
