Method

我的制作方式

Define

定义视觉目标

先明确画面风格、角色识别度、反馈强度和性能边界。

Decompose

拆解技术路径

把目标拆成光照、材质、管线、事件和工具参数。

Build

实现与验证

用可解释的代码和可调参数快速迭代，保留调试输出。

Polish

回到体验

最终用画面稳定性、交互反馈和可维护性检验方案。
